# FIAP - Análise e Desenvolvimento de Sistemas

Repositório criado para organizar os exercícios, projetos e conteúdos desenvolvidos durante o 2º ano do curso de Análise e Desenvolvimento de Sistemas na FIAP.

## 🗄️ Database

Exercícios e práticas desenvolvidos em aula utilizando SQL e PL/SQL.

### Conteúdos praticados

- Criação e manipulação de tabelas
- INSERT, UPDATE e DELETE
- Blocos PL/SQL
- Variáveis
- Estruturas condicionais
- FOR LOOP
- WHILE LOOP
- LOOP e EXIT WHEN
- DBMS_OUTPUT
